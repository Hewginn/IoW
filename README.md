# IoW

## Introduction

Internet of Wine *(IoW)* is an IoT prototype designed for monitoring of vineyards.
This repo contains the implementation of the server.
The repo of the sensor node can be found here: [https://github.com/Hewginn/IoW](https://github.com/Hewginn/IoW-Node)

## Install (Windows, Docker)

- **Docker Desktop** application
- `git clone https://github.com/Hewginn/IoW.git`
- `docker compose up -d --build`

## Run

- `docker compose up -d`
- Available on `http://localhost:29083/`
